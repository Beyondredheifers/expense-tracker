# Local Expenses

A personal expense tracker that runs entirely in your browser.

- No API
- No account
- No backend
- Data stays in localStorage on this device

## Use it now

Open `index.html` in any browser.

Optional local server:

```bash
python3 -m http.server 8000
```

Then visit http://127.0.0.1:8000

## Put it on GitHub Pages

1. Create a new public repo, for example `expense-tracker`.
2. Upload `index.html` and `manifest.json`.
3. GitHub → Settings → Pages → Source: Deploy from a branch → `main` / root.
4. Open the Pages URL on your phone and add it to the home screen.

## Backup

Use **Export JSON** before clearing browser data.
Use **Import JSON** to restore.
